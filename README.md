# B.Tech Student Progress AI Tracker

## Project Overview

B.Tech Student Progress AI Tracker is a Python and MySQL based student performance tracking system.

The system stores student details, subjects, marks and grades. It also analyzes student performance based on their marks.

## Features

- Add student details
- Store Roll Number, Name, Email, Phone, Branch and Semester
- Add 6 subjects and marks
- Automatically calculate grades
- Automatically calculate average marks
- Automatically calculate CGPA
- Identify weak subjects
- Analyze overall student performance
- Store student performance data in MySQL

## Technologies Used

- Python
- MySQL
- MySQL Connector for Python
